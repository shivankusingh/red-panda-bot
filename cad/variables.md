# Onshape variables from the sim

Generated by `python cad/sim_dims.py` from the model the policies were trained on. Paste these into an Onshape Variable Studio and build the skeleton sketch from them. If CAD needs a different number, change the sim too and retrain.

Frame: x forward, y left, z up, origin at the torso centre (same as the sim).

| Variable | Value (mm) | Meaning |
|---|---|---|
| `#torso_len` | 320.0 | torso box length (front-back) |
| `#torso_wid` | 100.0 | torso box width |
| `#torso_ht` | 50.0 | torso box height |
| `#hip_x` | 120.0 | hip axes ahead of / behind the torso centre (front +, hind -) |
| `#hip_side_y` | 40.0 | hip-side (abduction) axis out from the centre line, at torso mid-height |
| `#leg_plane_y` | 70.0 | hip pitch axis / leg plane out from the centre line (hip_side_y + 30 mm offset) |
| `#thigh` | 86.45 | hip axis to knee axis |
| `#shin` | 80.5 | knee axis to foot ball CENTRE |
| `#foot_r` | 10.0 | foot ball radius (the floor touches the ball, so foot tip = shin + foot_r) |
| `#tail_base_x` | -160.0 | tail wag axis, at the back face of the torso |
| `#tail_lift_dx` | 40.0 | tail wag axis to tail lift axis (backwards) |
| `#tail_seg1` | 110.0 | tail lift axis to mid-tail wag servo |
| `#tail_seg2` | 165.0 | mid-tail wag axis to tail tip |
| `#neck_x` | 170.0 | neck turn axis ahead of the torso centre |
| `#neck_z` | 25.0 | neck turn axis base above the torso centre |
| `#neck_nod_dz` | 30.0 | turn axis base to nod axis (up) |
| `#head_dx` | 40.0 | nod axis to head tilt axis (forward) |
